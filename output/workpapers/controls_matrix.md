# Controls matrix

Hedgehog Metrics, Inc. (synthetic data). Q1 2026. Generated by `python run.py`.

Each control in SPEC section 7. All are automated, detective controls that run at every monthly close. The Controller reviews each one.

| Control | What it proves (SPEC 7) | How the model tests it | Evidence | Owner | Reviewer | January | February | March |
|---|---|---|---|---|---|---|---|---|
| Completeness | Raw usage units received = free-tier + tiered + duplicate + late units. Nothing disappears silently. | Bridge A: units received by customer, product, and month, less each category, leaves zero. | reconciliation.md, bridge A | Billing engineering | Controller | PASS | PASS | PASS |
| Cutoff | Every row is assigned to a period by received_ts (UTC). Usage processed after the cutoff is covered by the lag estimate, and estimate vs actual is tracked each month. | Lag estimate equals the lag rate x processed usage revenue; late usage appears in the lag report with estimate vs actual. | lag_report.csv; close_checklist.md, BD3 | Finance Manager, Revenue Accounting | Controller | PASS | PASS | PASS |
| Close threshold | Unusual items are measured in aggregate against the threshold, and every passed item is logged with a running total. | Each month's unusual items, in aggregate, are below the threshold, and each is in the log. | passed_adjustments_log.csv | Finance Manager, Revenue Accounting | Controller | PASS | PASS | PASS |
| Pricing accuracy | Invoice totals are independently recomputed from the rate card and agree. | Every tiered invoice line recomputes as units x unit price; invoices are issued on business day 2. | invoices.csv; close_checklist.md, BD2 | Billing engineering | Controller | PASS | PASS | PASS |
| Integration | Every billing ledger row is mapped to the GL. GL account totals tie to the billing ledger. | Every ledger row is posted, memo-only, or an exception; GL totals by account are recomputed from the ledger; a rerun is identical. | gl_export.csv; exceptions.csv | Finance Manager, Revenue Accounting | Controller | PASS | PASS | PASS |
| Balance | Every journal entry balances, and the trial balance is in balance. | Debits equal credits in every daily journal entry and across the trial balance. | gl_export.csv | GL accountant | Controller | PASS | PASS | PASS |
| Rollforwards | Each rollforward ties to the GL. Contract liability = remaining credit x 0.80. | Every rollforward's closing balance equals its GL account at month end, with zero difference. | rollforwards.csv | GL accountant | Controller | PASS | PASS | PASS |
| Reconciliation | Zero unexplained difference each month. | Bridges A-D each show zero unexplained difference. | reconciliation.md | Finance Manager, Revenue Accounting | Controller | PASS | PASS | PASS |
